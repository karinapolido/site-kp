# KP Segurança dos Alimentos — Site Institucional

Site institucional responsivo em HTML/CSS/JavaScript puro.

## Estrutura

- `index.html` — página principal
- `assets/style.css` — estilos e identidade visual
- `assets/` — imagens e demais recursos

## Antes de publicar

1. Trocar o número do WhatsApp em `index.html`.
2. Trocar o e-mail de contato e o endereço do FormSubmit.
3. Trocar o link do Instagram.
4. Substituir o monograma provisório "KP" pelo logo oficial.
5. Adicionar fotos profissionais em `assets/`, se desejado.
6. Revisar os textos e serviços.

## GitHub Pages

No repositório do GitHub:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Depois, em Settings → Pages → Custom domain, informe seu domínio.

No provedor onde o domínio está registrado, configure os registros DNS conforme a documentação atual do GitHub:
https://docs.github.com/pt/pages/configuring-a-custom-domain-for-your-github-pages-site

## Formulário

O formulário está preparado para FormSubmit, mas o e-mail de destino é apenas um placeholder. Configure-o antes da publicação.
